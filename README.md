# 🎮 Tilevania Three — 2D Unity Platformer Game

Tilevania Three is a retro-style 2D pixel platformer game developed using the Unity Engine.
The game challenges players to survive hazards, defeat enemies, collect coins, and complete three progressively designed levels while managing limited lives.

This project was created as a complete gameplay-focused platformer featuring persistence mechanics, enemy elimination, collectibles, hazards, audio effects, and browser-playable WebGL deployment.

## 🕹️ Gameplay Objective

The player must:

* Collect as many coins as possible
* Avoid deadly hazards such as spikes and water
* Defeat enemies using bullets
* Use bounce mushrooms and ladders to navigate difficult areas
* Reach the exit portal to complete each level

The player has only **3 lives**.

If the player dies:

* one life is lost
* collected coins remain saved
* defeated enemies remain defeated

If all 3 lives are lost:

* full game session resets
* score resets
* lives reset
* persistence data resets
